# Vauxoo Theme

Dark VSCode theme built on the official [Vauxoo brand palette](https://www.vauxoo.com/assets) (Brand Manual 2024-2025).

## Design

- **Base**: Vauxoo black `#282C2F` / `#27282F`, elevated surfaces `#393B49`, text `#D6DAE0`.
- **Accents**: Vauxoo red `#AC0340` on the status bar, primary buttons, badges, focus rings and active tab border. Gold `#E4A900` cursor and active line number.
- **Flat design**: widget shadows disabled, solid borders and background tints convey hierarchy — as the brand manual mandates.
- **Syntax**: keywords in bright red `#E11E4D`, strings in light blue `#82BCCE`, functions in blue `#5498CC`, classes in gold `#E4A900`, constants in `#E9BE44`.
- **Semantics**: git decorations and terminal ANSI colors follow green=added, gold=modified, red=deleted.

## Install

From the Marketplace: search **Vauxoo Theme**, install, then `Cmd+K Cmd+T` → **Vauxoo Dark**.

From a `.vsix` file:

```
code --install-extension vauxoo-theme-<version>.vsix
```
